# PM25
La idea es trabajar con datos históricos de la Red Metropolitana de Monitoreo Atmosférico de Quito, que dispone de registros desde 2004 hasta 2025. La variable principal sería la concentración de PM2.5, que corresponde a partículas suspendidas en el aire con un diámetro aerodinámico menor o igual a 2.5 micrómetros.
